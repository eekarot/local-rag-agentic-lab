# 这里放你的文档（本目录不随仓库提供语料）

仓库**不携带任何语料**：文档有版权、体积大、而且和你的业务无关。你把自己要检索的
Markdown / TXT / PDF 放进这个目录，下面一条命令就会把它们变成可检索的向量库。

## 放法

```text
data/
├── README.md              # 本文件（唯一随仓库提交的文件）
├── md/                    # 建议按主题或来源分子目录，文件名会出现在答案的「来源」里
│   ├── 产品手册/
│   │   ├── 安装.md
│   │   └── 常见问题.md
│   └── 内部规范/
│       └── 代码风格.md
└── pdf/
    └── 行业白皮书-2026.pdf
```

要点：

- **递归扫描**：子目录多深都行，`data/` 下任意层级都会被扫到；
- **文件名就是 `doc_key`**：`md/产品手册/安装.md` 这个相对路径会进状态表，`--only` 也用这个写法；
- **一个主题一个文件**：切分按章节标题做边界，标题结构越清楚，切出来的块越干净；
- **别放锁文件/临时文件**：只认下列后缀。

## 支持的格式

| 后缀 | 说明 |
|---|---|
| `.md` | 首选。按 `#` 标题层级切父块（章节边界就是语义边界） |
| `.txt` | 纯文本，按段落/空行切 |
| `.pdf` | 能解析，但**页码信息目前没有落库**（源文件偏移为 NULL），溯源只能到文档级 |

需要别的后缀（如 `.rst`）用 `--patterns` 覆盖：

```powershell
python scripts/ingest.py --dir data --patterns "**/*.md" "**/*.rst"
```

## 放好之后

```powershell
# 先试跑：只切分不落库，看清楚会切出什么
python scripts/ingest.py --dir data --dry-run

# 真正导入（可反复执行，已完成的不重算）
python scripts/ingest.py --dir data

# 看进度 / 失败清单
python scripts/ingest.py --status
python scripts/ingest.py --failures
```

## 体积预期

实测 1,467 篇 Markdown（约 30 MB 源文本）→ 25,411 个父块 / 38,865 个子块，
建库约 **33 分钟**（CPU + Ollama `bge-m3`）。首次导入慢是正常的：每个子块都要算一次
embedding，之后重复导入会走内容 hash 缓存，几乎瞬时。

> 本目录已在 `.gitignore` 里排除（只放行本文件），你的文档不会被误提交。
