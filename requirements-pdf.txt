#
#   pip install -r requirements-pdf.txt

# 为什么单独一份：PyMuPDF 的许可证是 **AGPL-3.0 或商业授权**（不是 Apache-2.0）。

# 与 B11 定案（本项目 Apache-2.0，让别人能随便用）冲突。
#
# 所以：
#   * 不装它，md/txt 一切正常（代码对 pymupdf 做惰性导入，见 NOTICE 第三节）；
#   * 要解析 PDF 才装；
#   * 商用闭源请自行购买 Artifex 的商业授权，或接受 AGPL 的分发义务。
#
# 只想要 PDF 纯文本、不要页码/字号/bbox 的话，requirements.txt 里的 pypdf
# （BSD-3-Clause）本身够用，不必装这个。
